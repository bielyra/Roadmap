# Trilha de Fundamentos — Ciência da Computação

Projeto pessoal de estudo e revisão dos fundamentos da Ciência da Computação, construído como uma página web interativa de referência progressiva.

## Motivação

O projeto nasceu com três objetivos principais:

- **Consolidar o conhecimento adquirido** na universidade e no estágio, identificando e suprindo lacunas na base técnica.
- **Servir como trilha de estudos** para revisão contínua dos fundamentos — útil tanto para o estágio atual quanto para a preparação ao mercado de trabalho privado e/ou concursos públicos na área de TI.
- **Praticar desenvolvimento front-end** de forma progressiva: iniciando com HTML e CSS puros, com planos futuros de incorporar JavaScript e possivelmente um framework para animações e interatividade.
