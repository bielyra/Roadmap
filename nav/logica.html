Lógica & Matemática

Não é preciso ser matemático, mas alguns fundamentos são indispensáveis. A boa notícia: você aprende o que precisa enquanto programa, não em abstrato.

Lógica proposicional e booleana

E, OU, NÃO, XOR. Tabelas-verdade. Leis de De Morgan. São a base de toda condicional e toda estrutura de controle que você escreve. Também essenciais para entender operações bit a bit.

Boolean algebraBitwise opsDe Morgan

Matemática discreta

Conjuntos, relações, combinatória, indução matemática. Aplicada diretamente em análise de algoritmos, criptografia e banco de dados relacional. É a matemática da computação.

ConjuntosCombinatóriaInduçãoPermutações

Teoria dos grafos

Vértices, arestas, grau, conectividade, planaridade. O modelo matemático que está por trás de redes sociais, sistemas de rotas, compiladores e banco de dados relacionais.

GrafosÁrvoresFluxo

Probabilidade e estatística básica

Média, mediana, desvio padrão, distribuições. Imprescindível se você for trabalhar com dados, machine learning ou até análise de performance de sistemas. Também essencial para entender testes A/B.
