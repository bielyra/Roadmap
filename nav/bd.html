Habilidade prática

Banco de Dados

Dados são o ativo mais valioso de qualquer sistema. Saber modelar, consultar e otimizar bancos de dados é uma das habilidades mais cobradas no mercado — independente da stack.

SQL fundamental

SELECT, JOIN (inner, left, right, full), GROUP BY, HAVING, subconsultas, CTEs e window functions. SQL é a habilidade de banco de dados mais cobrada em entrevistas, disparado. Pratique muito.

🔥 SQLJOINsCTEsWindow functions

Modelagem relacional

Entidades, atributos, relacionamentos e normalização (1NF, 2NF, 3NF). Um banco mal modelado é fonte de problemas eternos. Aprenda a fazer um bom diagrama ER antes de criar qualquer tabela.

NormalizaçãoDiagrama ERChave primária/estrangeira

Índices e performance

Como um índice funciona internamente (B-Tree), quando criar e quando evitar, e como usar EXPLAIN/ANALYZE para diagnosticar queries lentas. Habilidade extremamente valorizada e raramente ensinada em cursos básicos.

🔥 ÍndicesEXPLAINQuery planningB-Tree

Transações e ACID

Atomicidade, consistência, isolamento e durabilidade. Entender transações é fundamental para não perder dados em casos de falha ou concorrência. Aprenda sobre níveis de isolamento e problemas como dirty reads.

ACIDTransaçõesIsolation levelsLocks

Bancos NoSQL

Quando e por que usar bancos não-relacionais: MongoDB (documentos), Redis (cache e chave-valor), Cassandra (alta escala), Elasticsearch (busca full-text). Não é "SQL vs. NoSQL" — é a ferramenta certa para cada problema.

🛠️ Tecnologias

PostgreSQL + Redis

PostgreSQL é o banco relacional open-source mais sofisticado. Redis é onipresente para cache. Domine os dois.

📈 Mercado de trabalho

PostgreSQL e MySQL dominam os relacionais. Redis é quase universal para cache. MongoDB e Elasticsearch aparecem em muitas vagas de backend. Saber escrever queries SQL complexas e otimizadas é diferencial imediato em entrevistas.
